## Method

이미지를 Patch 여러개로 쪼갬

각각 Patch를 flatten 시켜서 projection 해서 1차원 임베딩 지정

BERT모델에서 나온 [CLS] 토큰 처럼 $x_{class}$를 만들어서 맨 앞 sequence에 대입. (N(0,0.02^2) 에서 샘플링 한다고 함)

position embedding을 이용해서 이미지 위치 정보 주입. 이미지 위치에 대한 정보가 ViT에서는 이 부분만 나와있음.

self-attention 구조로 local성을 띄는 inductive bias를 줄이고 self-attention 레이어로 시퀀스사이의 정보를 global하게 정보를 해석.
(CNN의 local receptive field 기반 inductive bias를 거의 사용하지 않고, self-attention을 통해 모든 patch 간의 관계를 직접 모델링)

마지막 Transformer Encoder의 [CLS] 출력 $z_L^0$을 classification head에 넣어 class prediction을 수행 (pre-train시에는 MLP 2번)

평탄화 전에 CNN을 하고 진행하는 방법도 있음. 이를 hybrid 모델로 표현하는데 작은 계산에서는 기존 보단 성능이 약간 높지만 계산량이 많아지면 차이가 없어짐.

해상도마다 patch수가 다를 수 있음.

### Attention Distance

네트워크 깊이마다 각각 헤드에서 Attention distance가 어떻게 되는지 관찰. (테스트 데이터셋에서 진행)

$$d_{ij} = \sqrt{(x_i-x_j)^2 + (y_i-y_j)^2}$$

$$D_{\mathrm{head}} = \frac{1}{N}\sum_i\sum_j A_{ij}d_{ij}$$

d는 쿼리간의 거리 
A는 어텐션값 (모델 내부의 attn 불러오기. 대충 차원이 [B,H,W,W] 이럴 듯)
N은 총 개수 (N= PxP)

Attention distance → 각 head가 공간적으로 얼마나 멀리 보는가?

-> 네트워크 깊이가 깊을 수록 global하게 볼려는 ViT 모델의 특성이 두드러짐

### Attention maps

이미지하고 Attention Rollout의 heatmap을 overlay 시켜서 관찰할거임. (테스트 데이터셋에서 진행)

각 레이어의 attentions 불러오고 저장

attention을 각 레이어에서 head 평균내기

residual connection을 고려하여 attention = attention + I 하기

row normalization 하고 각 attention에 대해서 누적 내적을 통해 누적 시키기

patch 번호라고 할때 [x,y]에 대해 볼때 $\sum_i$ [x,i] \dot [i,y]$ 이러므로 합당함.

아래는 GPT가 짜준 코드인데 일단 참고만.

```python
def attention_rollout(attentions):
    # attentions:
    # [layer][batch, heads, tokens, tokens]

    rollout = torch.eye(
        attentions[0].size(-1),
        device=attentions[0].device
    )

    for attn in attentions:

        # 1. head 평균
        attn = attn.mean(dim=1)

        # 2. residual connection
        eye = torch.eye(
            attn.size(-1),
            device=attn.device
        )

        attn = attn + eye

        # 3. row normalization
        attn = attn / attn.sum(
            dim=-1,
            keepdim=True
        )

        # 4. 누적
        rollout = attn @ rollout

    return rollout
```
