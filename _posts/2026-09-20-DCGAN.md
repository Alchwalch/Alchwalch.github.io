## Introduction

GAN을 쓴 결과 성능이 좋게 나오지는 않았다. 예상했던 결과이며 이를 Convolution과 같이 개선한 DCGAN을 보겠다.

## Reference

[Unsupervised Representation Learning with Deep Convolutional Generative Adversarial Networks](https://arxiv.org/abs/1511.06434)

## method

사실 DCGAN은 특별한 구조적 변형은 없고 GAN의 단점을 개선 하는데에 집중을 둔 모델이다. 기존 GAN은 MLP를 사용했는데 DCGAN에서는 Convolution을 사용한다. 아래 그림은 G(z)를 시각화한 모델이며 D는 이와 반대로 흐른다고 보면 된다.

![DCGAN1](assets/img/DCGAN1.png)

Fully connected 레이어를 convolution layer로 바꾸는데에 논문은 조건을 추가한다. GAN과 비교하며 DCGAN의 Discriminator와 Generator에서 어떤 부분을 바꿨는지 알아보자.

### Discriminator

Convolution을 사용할 때 보통 pooling을 사용해서 사이즈를 축소 시켰던 것과 달리 stride를 이용해서 축소시킨다. LeakyReLU를 이용하는 것은 동일하지만 대신 0.1 에서 0.2로 더 폭이 넓어졌고 깊이가 깊어짐에 따라 BatchNormalization을 매 레이어마다 넣는다.

아래 코드는 DCGAN에 사용된 구조이며 [GAN](https://alchwalch.github.io/posts/GAN/)과 같이 참고해서 보면 좋다. [영상](https://www.youtube.com/watch?v=IZtv9s_Wx9I)에 나온 그대로이다. 

```python
class Discriminator(nn.Module):
  def __init__(self,channel_img,feature_dim=128):
    super().__init__()
    self.disc = nn.Sequential(
        nn.Conv2d(
            channel_img,feature_dim,kernel_size=4,stride=2,padding=1
        ), # -> 32
        nn.LeakyReLU(0.2),
        self._block(feature_dim,feature_dim*2,4,2,1), # 32 -> 16
        self._block(feature_dim*2,feature_dim*4,4,2,1), # 16 -> 8
        self._block(feature_dim*4,feature_dim*8,4,2,1), # 8 -> 4
        nn.Conv2d(
            feature_dim*8,1,kernel_size=4,stride=2,padding=0
        ),
        nn.Sigmoid()

    )

  def _block(self,in_channels,out_channels,kernel_size,stride,padding):
    return nn.Sequential(
        nn.Conv2d(
            in_channels,out_channels,kernel_size,stride,padding,bias=False
        ),
        nn.BatchNorm2d(out_channels),
        nn.LeakyReLU(0.2)
    )

  def forward(self,x):
    return self.disc(x)
```

### Generator

논문에서 fractional-strided convolution이라고 되어 있는데 fractional convolution은 *nn.ConvTranpose2d* 와 같은 개념이다. 아래는 그림은 이와 관련된 내용이고 더 자세한 설명은 [이전 블로그](https://alchwalch.github.io/posts/VAE/)에 적어놓았다.

![DCGAN2](assets/img/vae2.png)

논문에 나온대로 Generator에서 활성화 함수는 ReLU를 쓰고 마지막에는 Tanh를 쓴다. BatchNormalization을 매 레이어마다 쓰는건 Discriminator와 이유가 같다.

```python
class Generator(nn.Module):
  def __init__(self,z_dim,channel_img,feature_dim=64):
    super().__init__()
    self.gen = nn.Sequential(
        self._block(z_dim,feature_dim*16,4,1,0),
        self._block(feature_dim*16,feature_dim*8,4,2,1),
        self._block(feature_dim*8,feature_dim*4,4,2,1),
        self._block(feature_dim*4,feature_dim*2,4,2,1),
        nn.ConvTranspose2d(
            feature_dim*2,channel_img,kernel_size=4,stride=2,padding=1
        ),
        nn.Tanh()
    )

  def _block(self,in_channels,out_channels,kernel_size,stride,padding):
    return nn.Sequential(
        nn.ConvTranspose2d(
            in_channels,out_channels,kernel_size,stride,padding,bias=False
        ),
        nn.BatchNorm2d(out_channels),
        nn.ReLU()
    )

  def forward(self,x):
    return self.gen(x)
```
